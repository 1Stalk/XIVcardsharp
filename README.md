# XIVcardsharp

Get the umbrella faster. Think a lot less.

Smart Triple Triad solver and tournament autoplay for FFXIV.

</div>
<!-- Repository Header End -->

## Install

1. Dalamud → **Settings** → **Experimental**
2. Add custom repository: `https://raw.githubusercontent.com/1Stalk/DalamudPlugins/main/pluginmaster.json`
3. Install **XIVcardsharp** from the plugin installer

## Features

Open Tournaments · Tournament Draft · Battlehall & PvP · Friendly Matches

Type `/cardsharp` in-game, pick a mode, and turn it on. The solver drafts optimal decks and plays winning moves automatically.
